# Contributing

1. Create a focused branch for each change.
2. Add tests for successful and rejected inputs.
3. Preserve the distinction between computed output, checked certificate, and formal proof.
4. Do not let an AI model self-certify a result.
5. Document resource limits and failure behavior for new operations.
6. Run python -m pytest before submitting changes.

Architecture and interfaces are evolving. Mark unimplemented capabilities as unsupported rather than implying they work.
